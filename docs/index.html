Enterprise Document Q&A

Ask a question about a small set of company documents (security policy, audit procedure, risk report, handbook, incident response plan). It answers with page citations, says so when the documents don't cover the question, and only searches the files your role is allowed to see. Everything runs in your browser.

    How it works

    The documents are split into 512-character chunks. Each question is scored against the chunks with BM25 and TF-IDF, and the two rankings are merged with reciprocal rank fusion. Before any of that, chunks from documents above your role's clearance are removed, so a restricted file can't leak into an answer.

    The answer is quoted straight from the best matching sentences, with the document and page. If too few of the question's key terms show up in the top passages, it declines instead of guessing. Try asking about P1 incident response as an employee and then as compliance.

    This page is a JavaScript port of the Python retrieval code in the repo. The full app (FastAPI + Streamlit) can also generate answers with an LLM and run RAGAS evaluation.
